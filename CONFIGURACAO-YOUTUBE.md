# Chave YouTube na compilação local

A chave não é publicada nos fontes. Em PlatformConfig.java, preencha YOUTUBE_API_KEY privadamente antes de compilar. Uma chave embutida no APK pode ser extraída e consumir a cota do projeto. Preserve a restrição à YouTube Data API v3. O endereço oficial de atualizações já está integrado, com controle de verificação automática.
