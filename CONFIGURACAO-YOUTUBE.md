# YouTube no LivePulse 2.4.8

O APK público não inclui API Keys ou Client Secrets. Os Client IDs públicos de Twitch e Kick permanecem integrados.

Em Integrações, use Conectar YouTube para autorizar sua conta Google (o cadastro OAuth atual ainda está em testes e requer usuários de teste). Alternativamente, toque em Configurar consultas privadas e insira sua própria API Key. Ela é armazenada criptografada no aparelho e não é exportada no backup. Chaves já salvas são preservadas ao atualizar.

A Kick continua exigindo configuração privada do Secret no aparelho para o fluxo local. A consulta de atualizações usa o endereço oficial integrado, com opção de ativar/desativar a verificação automática. Nenhuma atualização é instalada sem confirmação do Android.
