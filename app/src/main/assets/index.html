Preferências do monitor

Suas chaves são pessoais. No Android, ficam criptografadas no armazenamento privado do aplicativo. O radar ativo usa o intervalo escolhido; em segundo plano, o Android pode reduzir a frequência.

Campos em branco preservam as credenciais já salvas. Cadastre outras plataformas abaixo usando uma API JSON compatível.

Outra plataforma

Adicione uma integração com nome e API personalizados.

Use {channel} no lugar do identificador do canal. A integração consulta uma API HTTPS que retorna JSON por GET. Autenticação sem token ou com Bearer.

Sem um campo de link, o alerta abre o link do canal cadastrado. O ID precisa mudar a cada nova live para evitar alertas repetidos. Exemplo de resposta: {"data":{"is_live":true,"stream":{"id":"live-123","title":"Minha live"}}}.

Depois de salvar, selecione a integração no Seu radar e informe o link e o identificador do canal. APIs com outro formato de autenticação ou que só retornam HTML precisam de um adaptador próprio.
